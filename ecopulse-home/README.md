
# EcoPulse Foundation — Official Website

The official website of **EcoPulse Foundation**, a nonprofit organization based in Jérémie, Haiti, dedicated to environmental education, youth empowerment, waste management, and sustainable community development.

## Overview

The website provides information about EcoPulse Foundation, its mission, leadership, environmental programs, community initiatives, and opportunities for engagement.

The website is built with HTML, CSS, and JavaScript, hosted on Cloudflare Pages, and managed through GitHub.

## Environmental Programs

### TREES Program

**Training for a Resilient Environment and Empowered Solutions**

TREES is EcoPulse Foundation's environmental education and youth leadership initiative. Through immersive training, practical workshops, and community engagement, the program develops young environmental leaders equipped to address environmental challenges in Haiti.

### School Garden Project

The School Garden Project is an initiative focused on environmental education through school-based gardens. It promotes sustainable agriculture, ecological awareness, and hands-on learning among students.

## TREES Application System

The online application system connects the website to Google Apps Script and Google Sheets.

**Application workflow:**

`Application Form → Google Apps Script → Google Sheets → Email Notifications`

The system includes form validation, application record management, and automated email notifications for applicants and the EcoPulse team.
